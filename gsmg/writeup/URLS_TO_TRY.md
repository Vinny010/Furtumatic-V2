# gsmg.io pages to try

The puzzle's URL convention is lowercase, no spaces, phrase-as-path
(e.g. `gsmg.io/theseedisplanted`), and one page is reached by a SHA-256
path: `gsmg.io/89727c59...` = sha256 of the first puzzle's text.

So each candidate is worth trying **twice** — as the plain phrase and as its
SHA-256 hex.
